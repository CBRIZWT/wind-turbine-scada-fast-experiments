# 实施计划

1. 为连续窗构造、摄氏度反缩放、24 h 事件标签、CfC-style 单元与事件匹配先写单元测试。
2. 实现只读数据加载与共同温度通道对齐；对大数组使用 memory map。
3. 实现 NBM、PCA+EWMA、Transformer、普通 LNN 与 Reptile-LNN。
4. 固定种子 `20260809`，执行缩减训练和相同适配预算。
5. 生成逐模型预测误差、LOEO 阈值、事件指标、逐点指标和训练日志。
6. 输出 `metrics.csv`、`metrics.json`、`事件逐折.csv`、`论文检索矩阵.csv` 与至少三张 PNG 图。
7. 运行 pytest、compileall、结果完整性检查，并按预注册规则给出“有效/无效/证据不足”判断。
